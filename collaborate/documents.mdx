---
title: "Store and find documents"
description: "Upload documents for an entity and find them later."
---

**Documents** keeps your files organized by entity and document type.

## Find a document

1. In the sidebar, select **Documents**.
2. Choose the entity whose documents you want to see.
3. Find the file and select **Download** to save it.

You can also open an entity's files from the **Entity Documents** tab on its page in **Legal Entities**.

## Upload a document

1. In **Documents**, select **Add Document**.
2. Choose the document type in **Select document type**. If the document is for a specific year, choose it in **Select financial year**.
3. Select **Attach file** and choose the file.
4. Select **Add document**.

Commenda confirms the upload and shows the folder it went to. Select **Go to file** to open it.
