---
title: "Update an incorporation participant"
openapi: "PATCH /partner/incorporation/{incorporationId}/participants/{participantId}"
---

Partially updates an existing incorporation participant.

Use this endpoint when a customer needs to:

- Correct a participant's director/shareholder roles or shareholder ownership percentages after registration.
- Repoint a participant to a different Commenda OS person or business entity (for example, after fixing a wrong `resourceId` was used during registration).

The request body must include at least one of `roles` or `resource`. Any field that is omitted is left unchanged on the participant.

## Request fields

| Field | Behavior |
| --- | --- |
| `roles` | Optional. When provided, fully replaces the participant's existing roles. Send the complete desired set; omitted roles are removed. |
| `resource` | Optional. When provided, replaces the underlying Commenda OS person or business entity the participant points to. Includes `resourceType` (`KEY_PERSON` or `BUSINESS_ENTITY`) and `resourceId`. |

A request that omits both fields is rejected with a `400` error.

## Update roles only

Send a `roles`-only payload to fix director/shareholder configuration without changing the underlying resource:

```json
{
  "roles": [
    {
      "role": "DIRECTOR"
    },
    {
      "role": "SHAREHOLDER",
      "ownershipPercentage": 40
    }
  ]
}
```

## Update the underlying resource only

Send a `resource`-only payload to repoint the participant to a different Commenda OS person or business entity, keeping the existing roles intact:

```json
{
  "resource": {
    "resourceType": "KEY_PERSON",
    "resourceId": 18
  }
}
```

## Update both fields

Send both fields when you need to swap the underlying resource and adjust roles in the same request:

```json
{
  "resource": {
    "resourceType": "KEY_PERSON",
    "resourceId": 18
  },
  "roles": [
    {
      "role": "DIRECTOR"
    },
    {
      "role": "SHAREHOLDER",
      "ownershipPercentage": 50
    }
  ]
}
```

## Response

The response returns the updated participant and the refreshed `incorporationValidation` for the incorporation.

```json
{
  "participant": {
    "id": "participant_123",
    "participantType": "INDIVIDUAL",
    "resource": {
      "resourceType": "KEY_PERSON",
      "resourceId": 18
    },
    "roles": [
      {
        "role": "DIRECTOR"
      },
      {
        "role": "SHAREHOLDER",
        "ownershipPercentage": 50
      }
    ],
    "documents": []
  },
  "incorporationValidation": {
    "isComplete": false,
    "missingRequirements": [],
    "invalidRequirements": [
      {
        "code": "SHAREHOLDER_OWNERSHIP_TOTAL_INVALID",
        "path": "participants.shareholders",
        "message": "Shareholders ownershipPercentage values must total 100"
      }
    ]
  }
}
```

For Singapore private limited companies, shareholder ownership may not exceed 100 across registered shareholder participants. Updates below 100 are accepted, but incorporation validation remains incomplete until the shareholder total equals 100.
