---
title: "Assign tax codes to products"
description: "Give each product a tax code so Commenda applies the right rate."
---

A product tax code tells Commenda what you sell. Commenda uses it to decide whether a product is taxable in each jurisdiction and at what rate. Products without a code use the **Default product tax code** from **Settings**.

## Add a product

1. In **Global Indirect Tax**, select **Products**.
2. Select **Add new product**.
3. Enter the **SKU**, **Product name**, and **Product description**.
4. Choose a **Product tax code**.
5. Select **Add product**.

To find the right code, browse the [tax code list](/engine/indirect-tax/taxcode).

## Import products

1. In **Products**, select **Import products**.
2. Select **Download product template** if you need the file format.
3. Upload a CSV or Excel file and select **Continue to mapping**.
4. Match each **Table column** to a **CSV column**.
5. Choose whether to allow overriding product SKU and tax code, then select **Upload**.

You can also select **Connect integration** to sync products from a connected system.

## Change a product's tax code

1. Open the product.
2. Select **Edit tax code**.
3. Choose the new code and select **Update**.

**Taxability by region** on the product page shows how the code applies in each jurisdiction.
