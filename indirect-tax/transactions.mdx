---
title: "Import your transactions"
description: "Get your sales into Commenda so it can track exposure and prepare filings."
---

Commenda works out your exposure and your returns from your transactions. Import them by file, or connect the system you sell through.

## Import a file

1. In **Global Indirect Tax**, select **Transactions**.
2. Select **Import transactions**.
3. Choose how to import:
   - **Let Commenda import my transactions**: upload your file and the Commenda team imports it within 2 business days.
   - **Import transactions myself**: upload your file and match its columns to Commenda's columns.
4. If you import yourself, choose whether your amounts are **Tax exclusive** or **Tax inclusive**, map the **Required Columns**, and select **Upload**.

Select **View import logs** to see how an import went.

## Connect a system instead

Select **Connect integration** to sync transactions from your accounting, payments, or ecommerce system. See [Connect your systems](/settings/integrations).

## Review a transaction

Select a transaction to see its line items, the **Tax Breakdown** by jurisdiction, and the customer.

Each transaction has a **Status**:

| Status | Meaning |
| --- | --- |
| **Recorded** | Commenda has the transaction. |
| **To be filed** | The transaction goes into your next return. |
| **Locked** | The transaction is part of a filed return and can't change. |
| **Void** | The transaction doesn't count. |

To change a status, select the transaction and choose **Mark as to be filed**, **Mark as void**, or **Mark as locked**.
